دليل Claude Connectors التفاعلي · Skills Bank

المحتويات:
- index.html : الصفحة (الفيديو بفصول + دليل أي تطبيق + محاكاة عملية + نقاط وبادجات وشهادة)
- media      : الفيديو
- screens    : شاشات المحاكاة
- fonts      : الخطوط

الرفع على GitHub Pages:
1) اعمل Repository جديد (Public) وعلّم على Add a README file.
2) Add file ثم Upload files: افتح هذا الفولدر واسحب ما بداخله (index.html و fonts و screens و README_AR.txt و .nojekyll) ثم Commit changes.
3) في Commit تاني: ارفع فولدر media (الفيديو لوحده).
4) Settings ثم Pages ثم Branch: main و / (root) ثم Save.
5) بعد دقيقة أو اثنتين يظهر الرابط. جرّبه على الموبايل واللابتوب قبل إرساله.

ملاحظات:
- تقدّم المتدرب (النقاط والبادجات والشهادة) يُحفظ على جهازه فقط.
- قبل النشر العام: تأكد من رخصة الموسيقى والمؤثرات (Mixkit).
